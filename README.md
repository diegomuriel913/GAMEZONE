
# 🎮 GameZone — Tu universo gamer

GameZone es una página web dedicada a descubrir y explorar videojuegos. Cuenta con una interfaz inspirada en la estética cyberpunk, colores neón y tarjetas interactivas para ofrecer una experiencia visual moderna.

## ✨ Características

- 🔎 **Buscador:** encuentra videojuegos por su nombre.
- ❤️ **Favoritos:** guarda tus juegos preferidos y consérvalos al recargar la página.
- 🎯 **Filtros por categoría:** explora juegos según su género.
- 🕹️ **Tarjetas interactivas:** disfruta de efectos visuales al pasar el cursor.
- 📱 **Diseño responsive:** interfaz adaptada a pantallas de computador y móvil.
- 🌌 **Estética cyberpunk:** fondo oscuro, luces neón y efectos de interacción.

## 🎮 Videojuegos incluidos

- Cyberpunk 2077
- Minecraft
- Grand Theft Auto V
- eFootball
- Forza Horizon 5
- Elden Ring

## 🛠️ Tecnologías utilizadas

- HTML5 — estructura de la página.
- CSS3 — diseño visual, animaciones y adaptación a diferentes pantallas.
- JavaScript — buscador, filtros y gestión de favoritos.
- LocalStorage — almacenamiento local de los juegos favoritos.

## 🚀 Cómo ejecutar el proyecto

1. Descarga o clona el repositorio.
2. Abre la carpeta `GameZone`.
3. Abre `index.html` en tu navegador.
4. También puedes utilizar la extensión Live Server de Visual Studio Code para ver los cambios mientras desarrollas.

## 💜 Objetivo del proyecto

Crear una experiencia web gamer moderna, atractiva y sencilla de utilizar, poniendo en práctica conocimientos de HTML, CSS y JavaScript.
